# Raw dataset

- **Dataset:** BPI Challenge 2015 Municipality 1
- **File expected:** `BPIC15_1.xes`
- **Source:** official BPI Challenge 2015 / 4TU Research Data
- **Purpose:** external public process-mining dataset used for the SPAR Data Science capstone proof of concept.

The raw dataset is not committed to Git and is not SPAR production data.
Place the downloaded XES file here without changing its contents. Raw `.xes`, `.xml`, `.xes.gz`, and `.zip` files are intentionally excluded from Git. `DATA1.xml`, if present, is also kept local and untouched.
